# SNKL Family — Thiruvudaiyan Family Android App

Android Studio project for the Thiruvudaiyan Family / Sankaran Kovil family app.

## Features
- Family Tree
- Add/Edit Member
- Celebrations
- Timeline
- Stories
- Portrait Gallery
- Family Functions
- Relationship Finder
- Android file/photo chooser
- Portrait orientation
- Thiruvudaiyan Family branding

## Package
com.thiruvudaiyan.family

## Version
1.0

## Note
The Android shell wraps the supplied family web application. Firebase/Firestore credentials are not embedded unless supplied separately.
